# 📄 MarkItDown GUI - 문서 마크다운 변환 및 지능형 요약기

Microsoft의 [MarkItDown](https://github.com/microsoft/markitdown) 엔진을 기반으로, 다양한 오피스 문서 및 한국형 문서(HWP/HWPX)를 손쉽게 **Markdown(`.md`)** 형식으로 변환하고 **핵심 요약(Summary)**을 자동 생성해주는 **PySide6(LGPL v3)** 기반 데스크톱 GUI 애플리케이션입니다.

---

## ✨ 주요 기능

### 1. 폭넓은 문서 포맷 지원
* **한글 문서 특화 지원**:
  * **`.hwp` (한글 97~2010 OLE 바이너리)**: 16바이트 확장 제어 바이트 정밀 스킵 로직을 적용하여 글자 깨짐(외계어·비정상 한자) 없이 본문 텍스트 완벽 추출
  * **`.hwpx` (한글 OWPML XML)**: 단락 구조뿐만 아니라 표(`tbl`)를 분석하여 Markdown 테이블(`| col | ... |`) 문법으로 정밀 변환
* **MS Office 문서**: `.docx`, `.xlsx`, `.xls`, `.pptx`, `.ppt` (Microsoft MarkItDown 엔진 연동)
* **기타 문서 및 데이터**: `.pdf`, `.txt` (UTF-8, CP949 자동 감지), `.html`, `.csv`, `.json`, `.xml`

### 2. 지능형 핵심 요약 (Smart Document Summary)
* **TF-ISF 기반 단어 중요도 분석**: 단순 출현 빈도가 아닌 정보 가치가 높은 핵심 키워드 도출
* **위치 가중치(Position Bias)**: 공문서 및 보고서 특성을 반영하여 서론/개요(앞 25%)에 1.6배, 결론/기대효과(뒤 25%)에 1.3배의 중요도 부여
* **문장 완성도 필터링**: 표 파편, 단순 날짜·숫자 나열을 배제하고 온전한 서술형 정보 문장만 추출
* **중복 제거(MMR)**: 자카드 유사도를 검사하여 비슷한 내용의 문장 중복 선정을 차단
* **Markdown 요약 카드 부착**: 문서 상단에 `> [!NOTE]` 스타일의 깔끔한 요약 블록 자동 생성

### 3. 사용자 친화적 모던 GUI
* **배포 라이선스 안전성**: 상용 및 비공개 배포 시 소스코드 공개 의무가 없는 **PySide6 (LGPL v3)** 공식 적용 (PyQt6 자동 폴백 지원)
* **드래그 앤 드롭(Drag & Drop)**: 탐색기에서 파일을 창에 끌어다 놓으면 즉시 입력 경로 반영 및 출력 파일명(`.md`) 자동 제안
* **비동기 백그라운드 처리(`QThread`)**: 대용량 파일 변환 시에도 UI가 멈추지(Freeze) 않고 진행 상태 바 실시간 업데이트
* **편의 기능**:
  * 변환 결과 Markdown 즉시 미리보기
  * **📋 마크다운 복사**: 원클릭 클립보드 복사
  * **📄 파일 열기** 및 **📁 저장 폴더 열기** 단축 버튼

## 🛠️ 요구 사항 및 설치 (Requirements)

### 1. 파이썬 버전
* Python 3.10 이상 권장

### 2. 필수 라이브러리 설치
가상환경 활성화 후 필요한 패키지를 설치합니다:

```bash
pip install markitdown PySide6 olefile
```

> **라이선스 참고**:
> - `PySide6`는 **LGPL v3** 라이선스로, 소스코드를 공개하지 않는 상용/사내용 독점 소프트웨어 배포에 안전합니다.
> - `markitdown`은 **MIT** 라이선스입니다.

## 🖥️ 사용 가이드

1. **파일 지정**:
   * [파일 선택...] 버튼을 누르거나, 탐색기에서 대상 파일(docx, hwp, hwpx, xlsx, pptx, pdf, txt 등)을 창 위에 **드래그 앤 드롭**합니다.
   * 입력 파일명에 맞춰 동일 폴더에 `.md` 출력 경로가 자동으로 입력됩니다. (필요 시 [저장 위치 변경...]으로 수정 가능)
2. **옵션 선택**:
   * `문서 상단에 핵심 요약(Summary) 추가`: 문서 앞단에 핵심 요약 박스를 삽입할지 여부 선택 (기본 체크)
   * `변환 내용 미리보기`: 완료 후 하단 텍스트 창에 마크다운 표시
   * `변환 완료 후 대상 폴더 열기`: 작업 완료 시 Windows 탐색기로 결과 폴더 자동 오픈
3. **변환 실행**:
   * **[🚀 작업시작]** 버튼을 클릭합니다.
   * 작업이 완료되면 알림 메시지와 함께 마크다운 미리보기가 제공되며, **[📋 마크다운 복사]** 또는 **[📄 마크다운 파일 열기]**를 통해 즉시 활용할 수 있습니다.
4. **프로그램 종료**:
   * **[❌ 프로그램 종료]** 버튼을 클릭하여 창을 닫습니다.
